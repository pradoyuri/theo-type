# 10 Perfis de Estudantes de Teologia

Site estático pronto para GitHub Pages. Não requer Node.js, instalação ou processo de build.

## Publicar

1. Crie um repositório no GitHub.
2. Envie `index.html` para a raiz do repositório.
3. Em **Settings → Pages**, selecione **Deploy from a branch**.
4. Escolha a branch `main` e a pasta `/ (root)`.
5. Salve e aguarde o endereço público ser exibido.

Também é possível abrir `index.html` diretamente no navegador para testar.
